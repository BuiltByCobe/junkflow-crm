# JunkFlow CRM

JunkFlow is a compact CRM scaffold for junk removal and cleanout businesses.

Quick summary
- Itemized quote builder, dump-fee aware profit check, and rate card prototype.
- Static, mobile-friendly prototype for local testing.

Quick start
- Open index.html in your browser, or serve locally:
  python3 -m http.server 8000
  Visit: http://localhost:8000

Layout
- index.html — prototype UI
- README.md, LICENSE.md, CONTRIBUTING.md, SECURITY.md, CHANGELOG.md
- .env.example — environment placeholders
